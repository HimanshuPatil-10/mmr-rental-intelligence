# Tableau instructions

1. Open Tableau Public and create a new workbook.
2. Connect to `data/processed/tableau/mmr_rentals_for_tableau.csv`.
3. Drag `locality` to Rows and `monthly_rent_inr` to Text.
4. Add `bhk` and `furnishing` to Color and Detail.
5. Create a map using `lat` and `lon` with `rent_per_sqft_carpet_inr` for color.
6. Publish the workbook to Tableau Public.
7. Copy the published workbook link into the project README and the career assets.

The project exports a flat CSV for dashboard use and a separate locality summary for quick visual exploration.
